## 天机天气 API 技术分析

### API 接口能力

| 能力项 | 详情 |
|--------|------|
| 认证方式 | 基于APIKey的用户认证 |
| 传输协议 | HTTPS（加密传输） |
| 返回格式 | JSON（UTF-8编码） |
| 接口类型 | 基于坐标点的单点数据查询 |
| 首次开通 | 地面6要素（t2m/ws10m/wd10m/slp/rh2m/tp） |
| 免费试用 | 非商业用途用户首次免费2个月 |

### 支持的气象要素（API）

- 100米风速和风向
- 10米风速和风向
- 2米温度
- 降雨量
- 2米湿度
- 辐照度
- 总云量、低云量

### 数据产品线（4套开放数据）

| 产品 | 覆盖范围 | 分辨率 | 预报时长 | 更新频率 | 要素数量 |
|------|---------|--------|---------|---------|---------|
| **TJ-CN** 中国区域公里级融合数据 | 中国 | 2.5km（最高1km气温） | 10天 | 每日2次 | 50+ |
| **TJ1-CN** 中国区域3公里数据 | 中国（65°E~145°E, 5°N~65°N） | 3km | 15天 | 每日4次 | 161 |
| **TJ1-GB** 全球12公里数据 | 全球 | 12km | 15天 | 每日4次 | 161 |
| **TJ-GB** 全球次季节12公里融合数据 | 全球 | 12km | **46天** | 每日2次 | 20+ |

### 技术亮点

- **球立方网格** — 规避经纬网格两极畸变，提升并行效率
- **全球自由变焦** — 网格拉伸聚焦，区域公里级超精细化
- **异构加速** — 全球第一例业务运行的异构加速气象数值模式
- **非静力平衡** — 更真实还原中小尺度气象过程
- **超精细化地形** — 米级尺度地形拖曳作用
- **动力物理深度耦合** — 解决高分辨率"灰区"问题

### 数据使用许可

- 许可协议：**CC BY-NC 4.0**（署名—非商业性使用）
- 数据格式：NetCDF4（支持 Python/MATLAB/R/NCL/CDO/NCO）
- 支持批量下载（wget/curl）和自动化脚本
- 历史数据需单独申请（在线仅保留最近15天起报数据）

### 已有生态

- GitHub 开源项目 [tjweather](https://github.com/fengyucn/tjweather)（CLI工具 + MCP服务器）
- MCP 协议支持，可集成到 Claude Code 等 AI 工具
- 魔搭社区已上线中科天机高质量气象数据集
